# Skill Patch Proposal

## Tools
- `guideline_index_tool`
- `guideline_rag_tool`  (primary deliverable)
- `citation_verifier_tool`
- `mcp_federation_tool`

## Purpose
Add **clinical guideline / literature RAG** to ChatClinic: answer clinical questions with
evidence-grounded, `[REF#]`-cited answers retrieved from a guideline corpus and generated by a local
Qwen3-8B model, with a citation-faithfulness check. An MCP gateway lets the system also pull evidence
from external MCP servers (server-to-server).

## When to use
- Use `guideline_rag_tool` when the user asks a clinical management/treatment question that should be
  answered **from guidelines/literature** rather than free-form model knowledge.
- Use `guideline_index_tool` once before the first query, and again whenever the corpus changes.
- Use `citation_verifier_tool` after a grounded answer to confirm each cited claim.
- Use `mcp_federation_tool` to discover/call external MCP server tools, or set
  `external_evidence=true` on `guideline_rag_tool` to fuse external evidence into the answer.

## When not to use
- Do not use for questions outside the guideline corpus scope — the tool returns
  *"Insufficient evidence in the provided guidelines."* by design rather than guessing.
- Do not use as a substitute for patient-specific clinical judgment; outputs are research/education only.

## Modality
- note / mixed (clinical text; optional `source_context` from an uploaded note or FHIR bundle).

## Recommended stage
- on-demand (chat-triggered). `guideline_index_tool` is a one-time/maintenance build step.

## Depends on
- `guideline_index_tool` (FAISS index) for `guideline_rag_tool`.
- A reachable local LLM endpoint (`LOCAL_LLM_BASE_URL`, vLLM serving Qwen3-8B).
- `mcp_federation_tool` is independent (reads `mcp_servers.json`).

## Approval policy
- approval not required (read-only retrieval + generation; no writes, no PHI persistence).

## Produces
- `guideline_rag` Studio artifact: grounded answer + `[REF#]` references + retrieved passages + a
  citation-faithfulness report (`supported/total`).

# guideline_rag_tool

Clinical **guideline / literature RAG**: retrieve the most relevant passages from a curated guideline
corpus and produce an **evidence-grounded answer with inline `[REF#]` citations**, generated by a local
**Qwen3-8B** model (vLLM). Deterministic retrieval first, LLM grounding second.

## Contract
- Entrypoint: `plugins.guideline_rag_tool.logic:execute`
- Input: `{question, top_k=6, min_score=0.2, source_context?, verify=true, external_evidence=false, external_max=3}`
- Output: `{question, draft_answer, references[], passages[], uncertainty, used_fallback, model, verifier, studio}`
- HTTP: `POST /api/v1/guideline-rag/run`

## Behavior
- Retrieves top-k passages via FAISS (cosine), drops below `min_score`, assigns `REF1..REFk`.
- Grounds the answer strictly on those passages; returns *"Insufficient evidence in the provided
  guidelines."* when not covered.
- `external_evidence=true` federates to external MCP servers and merges their evidence (continuing REF#).
- `verify=true` runs the citation faithfulness check (see `citation_verifier_tool`).
- If the local LLM endpoint is unreachable, degrades to an extractive answer (top passages verbatim).

## Dependencies
Requires a built index (`guideline_index_tool`) and a reachable local LLM
(`LOCAL_LLM_BASE_URL`, default `http://localhost:8000/v1`). See `requirements.txt` and
`docs/medical_rag/`.

## Example
```
@guideline first-line antibiotics for outpatient community-acquired pneumonia
```
